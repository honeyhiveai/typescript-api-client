Built for tooling and automation

The right fit for admin scripts, CI integrations, dashboards, data migrations, and any workflow that manages HoneyHive as a resource.

Fully typed, end to end

Request and response types per endpoint, autocomplete everywhere. Catches shape mismatches at compile time instead of in production.
